# Financial Health Dashboard – Power BI

## Project Overview
This project is developed as part of the CodeAlpha Power BI Internship.

The Financial Health Dashboard helps analyze an organization's financial performance using interactive visualizations and real-time insights. The dashboard is designed especially for SMEs to monitor profitability, sales trends, and financial planning.

---

## Objectives
- Analyze company financial performance
- Visualize sales, profit, and COGS
- Track profitability trends over time
- Implement forecasting for budgeting and planning
- Create interactive and dynamic reports

---

## Dashboard Features
### Executive Dashboard
- Total Sales KPI
- Total Profit KPI
- Profit Margin KPI
- Total COGS KPI

### Visualizations
- Sales Trend Analysis
- Profit Trend Analysis
- Segment-wise Revenue Analysis
- Country-wise Sales Map
- Waterfall Chart for Profitability
- Forecasting Chart

### Interactive Features
- Slicers and Filters
- Dynamic Visualizations
- Drill-down Analysis
- Forecasting Insights

---

## Tools & Technologies
- Power BI Desktop
- Power Query
- DAX
- Excel Dataset

---

## Key Insights
- Sales increased consistently over time.
- Government segment generated highest revenue.
- Forecast predicts future business growth.
- Profit margins improved in recent periods.
